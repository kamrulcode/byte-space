## 🚀 Getting Started

Follow these steps to run ByteSpace locally.

### Prerequisites

- [Node.js](https://nodejs.org/) — preferably the LTS version
- npm, pnpm, yarn, or bun
- Git

### 1. Clone the repository

Replace `<your-github-username>` with your GitHub username or organization.

```bash
git clone https://github.com/<your-github-username>/bytespace.git
cd bytespace
```

### 2. Install dependencies

```bash
npm install
```

Use the package manager that matches your repository's lockfile.

### 3. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production

```bash
npm run build
npm run start
```

If environment variables are required, configure them in `.env.local`. Never commit API keys or other secrets to Git.
